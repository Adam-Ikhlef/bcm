# Security policy

## Supported versions

Only the latest release receives fixes.

## Reporting a vulnerability

Please **do not open a public issue** for security problems.
Use GitHub's private reporting: **Security → Report a vulnerability** on this repository.
Include the version, your operating system, and steps to reproduce. You will get a reply within a few days.

## What counts

- The installer or updater downloading or running something it should not
- Mods (`bus.json` / `.glb` files) being able to run code, read other files or crash the game in a way that harms the system
- Anything that leaks personal data

Gameplay bugs and crashes are normal issues, not security reports.
