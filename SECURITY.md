# Security Policy

## Supported Versions

Security updates are provided for the versions listed below:

| Version | Supported          |
| ------- | ------------------ |
| Latest release / `main` | :white_check_mark: |
| Older releases | :x: |

## Reporting a Vulnerability

**Please do not report security vulnerabilities through public GitHub Issues.**

If you discover a security issue in **Bus Company Manager**, please report it privately using one of the following methods:

* **GitHub Private Vulnerability Reporting:** Use the **Security** tab -> **Report a vulnerability**.
* **Email:** Send details to **ads.adam09@gmail.com**.

### What to Include

To help us reproduce and address the issue quickly, please include:

* Affected version, branch, or commit hash.
* Operating system and runtime/engine details.
* Clear step-by-step instructions to reproduce the issue.
* Potential impact and any proof-of-concept details (avoid including live exploits against external infrastructure).

## What to Expect

* **Acknowledgment:** We aim to acknowledge reports within **5–7 days**.
* **Updates:** We will keep you informed as we investigate and work on a fix.
* **Disclosure:** Please give us reasonable time to release a patch before disclosing the vulnerability publicly. We are happy to credit reporters if desired.

## Scope

Examples of security concerns in scope include:

* Unsafe loading or execution of untrusted mods, custom assets, or scripts.
* Path traversal or unintended file system access via save files, mods, or configuration parsing.
* Vulnerabilities in any official online services, APIs, or multiplayer components (if applicable).

Examples typically out of scope:

* Single-player save editing, money/fleet/reputation exploits, or local gameplay balance issues.
* Non-security bugs, crashes from unsupported/broken third-party mods, or feature requests.
